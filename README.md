# CV Builder App

A modern and responsive CV Builder built with **React**, **Vite**, and **React Bootstrap**. This application allows users to input, edit, and preview their general information, educational background, and work experience — all in a sleek, user-friendly interface.

---

##  Features

-  Add/Edit General Information (Name, Email, Phone)
-  Educational Experience (School, Degree, Date)
-  Practical Experience (Company, Role, Responsibilities, Dates)
-  Toggle between edit and preview modes for each section
-  State management using React’s `useState` hook
-  Responsive layout with React Bootstrap
-  Built with Vite for fast development and optimized build

---

##  Technologies Used

- React
- Vite
- React Bootstrap
- JavaScript (ES6+)
- Git & GitHub
